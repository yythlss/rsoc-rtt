## 二、RT-Thread 生态与产品线介绍

*王玉强老师详细讲解了RT-Thread的发展历程、开源生态及三条核心产品线。*

### 1. 生态发展现状

- **开源生态**：
  - RT-Thread 作为国产自研 RTOS，经历了近 20 年发展。
  - GitHub 星标达 **12.2k**，在国内拥有活跃的开源社区。
- **版本迭代**：
  - 内核版本已迭代至 **V5.3.0**，在国际 RTOS 开源领域保持活跃。

### 2. 核心产品线架构

| 产品线        | 特点                                                          |
| ---------- | ----------------------------------------------------------- |
| **Nano版**  | 极简版内核，包含实时内核、线程同步通信机制及最小实体（线程、时钟、中断、内存管理），基于 Apache 协议开源。   |
| **标准版**    | 基于标准 POSIX API，提供丰富的组件（如日志管理、网络协议栈、IoT 协议）及中间件，生态完整且高度可定制化。 |
| **Smart版** | 针对带 MMU 设备，采用混合微内核架构，实现内核态与用户态分离，提升安全性。                     |

## 五、RT-Thread 标准版启动流程（基于 STM32F407 + GCC）

*RT-Thread 在标准版（基于 STM32F407 + GCC 工具链）下的启动流程可以概括为「汇编上电 → RT-Thread 入口 → 板级/组件初始化 → 调度器启动 → main 线程运行」五个阶段。*

### 阶段一：芯片上电与汇编启动（Reset Handler）

1. MCU 上电后从复位向量跳入 `Reset_Handler`（位于启动汇编文件，如 `startup_stm32f407xx.s`）。
2. 依次完成：
   - 设置栈指针 **SP**。
   - 将 `.data` 段从 Flash 拷贝到 RAM，并清零 `.bss` 段。
   - 调用 `SystemInit()` 配置时钟、Flash 等待周期及中断向量基址。
3. 最后跳转到工具链约定的入口函数：
   - **GCC**：`entry()`
   - **MDK**：`__main`
   - **IAR**：`__iar_program_start`
     
     > 三者殊途同归，最终都会进入 RT-Thread 的统一入口 `rtthread_startup()`。

### 阶段二：RT-Thread 统一入口（rtthread_startup）

进入 `rtthread_startup()` 后，按顺序执行以下系统级初始化（期间会关闭全局中断，防止被打断）：

| 步骤  | 操作                                                                                                                  |
| --- | ------------------------------------------------------------------------------------------------------------------- |
| ①   | **关中断**：`rt_hw_interrupt_disable()`，防止初始化过程被中断打断。                                                                   |
| ②   | **堆初始化**：`rt_system_heap_init()`（若开启动态内存）。                                                                          |
| ③   | **板级初始化**：`rt_hw_board_init()` — 配置 SysTick、使能中断、初始化 Pin 驱动、初始化 UART 并绑定为控制台设备。                                     |
| ④   | **组件预初始化**：通过 `INIT_BOARD_EXPORT` 等宏注册的函数依次执行。                                                                      |
| ⑤   | **打印版本**：`rt_show_version()`，串口输出 RT-Thread logo（即终端看到的启动横幅）。                                                       |
| ⑥   | **内核对象初始化**：调度器 `rt_system_scheduler_init()`、定时器、信号量、IPC 等。                                                         |
| ⑦   | **创建系统线程**：<br>- **main 线程**（入口 `main_entry` → 最终调用用户 `main()`）<br>- **timer 线程**（软件定时器管理）<br>- **idle 线程**（负责资源回收） |

### 阶段三：启动调度器

调用 `rt_system_scheduler_start()`，从就绪队列中取出最高优先级线程，切换上下文，正式进入多线程抢占式调度状态。

> 注意：RT-Thread 中**优先级数字越小，优先级越高**。此时 main 线程、timer 线程、idle 线程等均参与调度。

### 阶段四：进入用户 main()

`main` 线程被调度后，执行 `main_entry()` → 调用用户编写的 `main()` 函数（位于 `applications/main.c`），例如：

```c
rt_kprintf("hello rt-thread\n");
rt_kprintf("hello soc 2026\n");
```
