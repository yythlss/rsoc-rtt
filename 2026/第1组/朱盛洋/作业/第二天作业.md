## 二、多线程理论基础

### 2.1 线程状态与转换

RT-Thread 中线程共有 5 种基本状态：

| 状态 | 宏定义 | 说明 |
|------|--------|------|
| 初始态 | `RT_THREAD_INIT` | 线程创建完成但未启动 |
| 就绪态 | `RT_THREAD_READY` | 线程已就绪，等待调度器分配 CPU |
| 运行态 | `RT_THREAD_RUNNING` | 线程正在执行 |
| 挂起态 | `RT_THREAD_SUSPEND` | 线程被挂起，不再参与调度 |
| 关闭态 | `RT_THREAD_CLOSE` | 线程已结束 |

**状态转换图：**
```
INIT → READY → RUNNING → SUSPEND
  ↓              ↑           ↓
CLOSE ←──────────┴─── READY ←┘
```

### 2.2 动态线程 vs 静态线程

| 特性 | 动态线程 (`rt_thread_create`) | 静态线程 (`rt_thread_init`) |
|------|------------------------------|---------------------------|
| TCB 分配 | 自动从堆分配 | 用户提供静态全局变量 |
| 栈空间 | 自动从堆分配 | 用户提供静态全局数组 |
| 内存释放 | 线程退出时自动释放 | 需要手动管理 |
| 适用场景 | 线程数量运行时可变 | 线程数量固定、资源受限 |

### 2.3 优先级与时间片

- RT-Thread 支持 32 个优先级 (0 最高，31 最低)
- 相同优先级的线程通过时间片轮转调度
- 高优先级线程可抢占低优先级线程

### 3.2 线程设计

#### 工作线程 1：`th_led1`（动态线程）

| 参数 | 值 |
|------|-----|
| 创建方式 | `rt_thread_create()` |
| 优先级 | 16 |
| 时间片 | 5 ticks |
| 栈大小 | 1024 bytes |
| 功能 | 每 500ms 翻转板载 LED_R (PF9)，打印计数与系统 Tick |

```c
static void th_led1_entry(void *parameter)
{
    rt_uint32_t count = 0;
    while (1)
    {
        rt_pin_write(LED_R_PIN, !rt_pin_read(LED_R_PIN));
        LOG_I("th_led1: count=%d, tick=%d", count++, rt_tick_get());
        rt_thread_mdelay(500);
    }
}
```

#### 工作线程 2：`th_led2`（静态线程）

| 参数 | 值 |
|------|-----|
| 创建方式 | `rt_thread_init()` |
| 优先级 | 16 |
| 时间片 | 5 ticks |
| 栈大小 | 1024 bytes (静态数组) |
| 功能 | 每 1000ms 翻转板载 LED_B (PF10)，打印计数 |

```c
static struct rt_thread th_led2_tcb;
static rt_uint8_t       th_led2_stack[1024];

static void th_led2_entry(void *parameter)
{
    rt_uint32_t count = 0;
    while (1)
    {
        rt_pin_write(LED_B_PIN, !rt_pin_read(LED_B_PIN));
        LOG_I("th_led2: count=%d", count++);
        rt_thread_mdelay(1000);
    }
}
```

#### 监控线程：`th_monitor`（动态线程，高优先级）

| 参数 | 值 |
|------|-----|
| 创建方式 | `rt_thread_create()` |
| 优先级 | **10**（高于工作线程的 16） |
| 栈大小 | 1024 bytes |
| 周期 | 2000 ms |
| 功能 | 监控 th_led1/th_led2 状态、剩余栈空间；按键控制 |

```c
static void th_monitor_entry(void *parameter)
{
    while (1)
    {
        rt_thread_mdelay(2000);
        /* 获取 th_led1 状态与剩余栈 */
        if (th_led1_tid != RT_NULL) {
            rt_uint32_t remained = get_remaining_stack(th_led1_tid);
            LOG_I("th_led1: state=%s, remaining_stack=%d/%d",
                   thread_status_str(th_led1_tid->stat),
                   remained, th_led1_tid->stack_size);
        }
        /* 获取 th_led2 状态与剩余栈 */
        if (th_led2_tid != RT_NULL) {
            rt_uint32_t remained = get_remaining_stack(th_led2_tid);
            LOG_I("th_led2: state=%s, remaining_stack=%d/%d",
                   thread_status_str(th_led2_tid->stat),
                   remained, th_led2_tid->stack_size);
        }
    }
}
```

#### 按键中断控制

使用 PA0 (WK_UP) 按键的上升沿中断，单次触发挂起/恢复 th_led1：

```c
static void key_callback(void *args)
{
    if (th_led1_suspended) {
        rt_thread_resume(th_led1_tid);
        th_led1_suspended = 0;
        LOG_I("KEY: th_led1 resumed");
    } else {
        rt_thread_suspend(th_led1_tid);
        th_led1_suspended = 1;
        LOG_I("KEY: th_led1 suspended");
    }
}
```

## 七、结果分析

### 7.1 线程调度验证

| 线程 | 优先级 | 周期 | 观察结果 |
|------|--------|------|----------|
| th_led1 | 16 | 500ms | 每 500ms 翻转 LED_R，打印 count 和 tick |
| th_led2 | 16 | 1000ms | 每 1000ms 翻转 LED_B，打印 count |
| th_monitor | 10 | 2000ms | 每 2000ms 打印两线程状态与栈剩余空间 |
| main | 10 | 1000ms | 打印 "Hello RT-Thread!" |

- **th_led1 和 th_led2 同优先级**：两者通过时间片轮转调度，th_led1 每 500ms 执行一次，th_led2 每 1000ms 执行一次，输出交替出现，符合预期。
- **th_monitor 优先级更高**：th_monitor 优先级为 10，高于工作线程的 16，能在唤醒后及时获取监控信息。
- **栈空间使用**：th_led1 使用了约 252/1024 字节（24%），th_led2 使用了约 248/1024 字节（24%），栈空间充足。

### 7.2 按键控制验证

板载按键 PA0 (WK_UP) 的上升沿中断触发时：
- 第一次按下：`th_led1` 被挂起（SUSPEND），LED_R 停止闪烁
- 第二次按下：`th_led1` 被恢复（READY），LED_R 恢复闪烁

### 7.3 系统集成验证

- `INIT_APP_EXPORT(thread_demo_init)` — 系统启动时自动加载执行，无需在 `main.c` 中手动调用
- `MSH_CMD_EXPORT(thread_dump, ...)` — 在 FinSH/MSH 命令行中可直接输入 `thread_dump` 查看所有线程信息

## 八、总结

本实验在 RT-Thread 操作系统下成功实现了：
1. **动态线程创建**：使用 `rt_thread_create()` 创建 th_led1 和 th_monitor
2. **静态线程创建**：使用 `rt_thread_init()` 创建 th_led2，静态定义 TCB 和栈空间
3. **线程监控**：高优先级监控线程周期性获取工作线程状态与栈使用情况
4. **按键控制**：通过 GPIO 中断实现 th_led1 的挂起与恢复
5. **系统集成**：自动加载与自定义 MSH 命令

实验结果表明，RT-Thread 的线程调度机制稳定可靠，同优先级线程按时间片轮转，高优先级线程可抢占低优先级线程，`rt_thread_suspend()/resume()` 能够有效控制线程执行状态。
