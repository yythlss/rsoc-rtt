## 二、RT‑Thread 基础认知

RT‑Thread 是国产开源实时操作系统，已经发展近 20 年。主要分为三个版本：

- **Nano**：轻量极简内核，适合资源较小的设备，Apache 开源协议；
- **标准版**：组件丰富，支持 POSIX 接口，网络、日志、IoT 中间件齐全；
- **Smart**：面向带 MMU 硬件，内核态用户态隔离，安全性更高。

## 三、RT‑Thread Studio 环境搭建

RT‑Thread Studio 是官方推出的一站式开发 IDE，能够极大简化 RT‑Thread 工程创建、配置、编译调试流程。环境搭建的完整步骤如下：

1. 安装 RT‑Thread Studio 软件，按照教程完成软件配置；
2. 打开 SDK Manager 工具，下载指定版本 RT‑Thread 源码，同时安装 STM32F4 系列芯片支持包；
3. 将 STM32F407 开发板通过 ST‑Link 调试器连接电脑，打开设备管理器确认电脑可以正常识别 ST‑Link 驱动，硬件链路无异常；
4. 在 IDE 内新建工程，芯片选型选择 STM32F407，内核选择标准版，串口参数设置波特率`115200`，数据位 8，停止位 1，无校验；
5. 工程创建完成后执行编译，编译成功会生成`.bin`和`.elf`两种格式固件文件；
6. 使用 ST‑Link 将固件烧录下载到开发板；
7. 打开串口终端工具，观察 RT‑Thread 开机启动日志，验证程序正常运行，同时可以使用断点调试功能，进行代码调试。

实操过程中会遇到一些常见问题：使用 ST‑Link 烧录的时候，如果提示固件版本过低报错，可以尝试更新 ST‑Link 固件，多使用不同工具尝试更新，规避工具版本不兼容问题。程序跑起来之后，在 msh 交互终端可以执行很多系统调试命令：`free`查看系统内存占用情况，`list_thread`查看全部线程，还有查看信号量、事件、互斥锁、定时器等命令，方便我们调试内核运行状态。我们主要修改`applications/main.c`，编写业务逻辑，例如循环打印 Hello

> 注意：ST‑Link 烧录报错，可尝试更新固件版本。

## 四、Markdown 笔记书写要点

日常笔记统一使用 Markdown 格式：

- 标题使用`#`、`##`分级；

- 代码片段用 ` `包裹，可标注语言实现高亮；

- 行内代码使用 ``代码``；

- 图片建议存放在工程内`figures`文件夹，使用相对路径，防止迁移丢失；

- 支持表格、加粗`**文字**`等格式。

  # 例：一级标题

  ##           二级标题

  ###             三级标题

  ....

  代码段

  ```c
  #include <stdio.h>
  
  int main()
  {
  	return 0;
  }
  ```

  表格

  | t1   | t2   |
  | ---- | ---- |
  | 1    | 2    |

  `高亮语法`

  **加粗字体**

## 五、Git 版本控制与协作

### 1. 基础配置

安装 Git 后，先配置全局用户名邮箱，生成 SSH 密钥，把公钥配置到 Gitee 实现免密推送。

![image-20260817220914333](../../../../../../figures/image-20260817220914333.png)

bash

```
git config --global user.name "自己名字"
git config --global user.email "自己邮箱"
```

![image-20260817220904172](../../../../../../figures/image-20260817220904172.png)

### 2. 基础工作流程

工作区修改文件 → `git add .`加入暂存区 → `git commit -m "提交说明"`本地提交 → `git push`推送到远端。

### 3. Fork‑PR 协作流程

1. 将上游仓库 Fork 到个人账号；
2. **不要直接修改 master 分支**，新建独立功能分支进行编写；
3. 完成修改推送个人仓库后，网页端创建 PR 提交给上游；
4. 若出现代码冲突，同步上游最新代码，手动处理冲突后再次提交推送。

常用简短命令：

bash

```
git init
git clone 仓库地址
git checkout -b day1
git pull
git fetch upstream
git remote add upstream 上游仓库地址
```
