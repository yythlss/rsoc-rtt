# RSOC26 Day1 学习笔记

## 1. Git 基础

Git 是分布式版本控制工具，可以记录文件的修改历史。常见流程为：

```text
工作区 -> 暂存区 -> 本地仓库 -> 远程仓库
```

常用命令：

```bash
git status                  # 查看文件状态
git diff                    # 查看修改内容
git switch -c <分支名>      # 创建并切换分支
git add <文件>              # 添加到暂存区
git commit -m "说明"        # 提交到本地仓库
git push -u origin <分支名> # 推送远程分支
```

本次作业中，`origin` 表示自己 Fork 的仓库，`upstream` 表示 RT-Thread 官方作业仓库。PR 用于请求维护者把个人分支的修改合并到官方仓库。

## 2. 裸机与 RTOS

裸机程序通常在完成初始化后进入 `while (1)`，各任务按照程序设计的顺序运行。RTOS 会把任务划分为不同线程，由调度器根据线程优先级和状态决定运行顺序。

```text
裸机：上电 -> 初始化 -> main -> while(1)
RTOS：上电 -> 内核初始化 -> 创建线程 -> 启动调度器
```

RT-Thread 中的 `main()` 通常在线程环境中运行，而不是负责所有系统初始化。

## 3. RT-Thread 启动流程

RT-Thread 的启动流程可以简单概括为：

```text
复位入口
  -> 板级和内核初始化
  -> 创建 main、定时器和空闲线程
  -> 启动调度器
```

几个主要函数：

- `rt_hw_board_init()`：完成板级初始化。
- `rt_system_timer_init()`：初始化定时器系统。
- `rt_system_scheduler_init()`：初始化调度器。
- `rt_application_init()`：创建应用相关线程。
- `rt_thread_idle_init()`：创建空闲线程。
- `rt_system_scheduler_start()`：启动线程调度。

RT-Thread 还可以通过 `INIT_BOARD_EXPORT`、`INIT_DEVICE_EXPORT`、`INIT_COMPONENT_EXPORT` 和 `INIT_APP_EXPORT` 等宏自动注册初始化函数，使不同组件按阶段完成初始化。
