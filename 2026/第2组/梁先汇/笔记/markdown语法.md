# Markdown 语法笔记

Markdown 是一种轻量级标记语言，用简单的符号即可写出排版良好的文档。

## 一、标题

使用 `#` 号表示标题，`#` 的数量代表标题级别（最多六级）。

```markdown
# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题
```

显示效果：

# 一级标题

## 二级标题

### 三级标题

## 二、代码段

使用三个反引号 ` ``` ` 包裹代码，反引号后可标注语言以启用语法高亮。

```c
#include <stdio.h>

int main()
{
	return 0;
}
```

## 三、表格

使用 `|` 分隔单元格，第二行的 `---` 用于分隔表头和内容。

```markdown
|   t1   |   t2   |
| ---- | ---- |
|   1   |   2   |
```

显示效果：

|   t1   |   t2   |
| ---- | ---- |
|   1   |   2   |

对齐方式：

| 语法 | 对齐方式 |
| ---- | ---- |
| `:---` | 左对齐 |
| `:---:` | 居中对齐 |
| `---:` | 右对齐 |

## 四、行内代码（高亮语法）

使用单个反引号包裹文字，可以 `高亮语法`，例如 `printf("hello")`。

## 五、字体样式

```markdown
**加粗字体**
*斜体字体*
***加粗斜体***
~~删除线~~
```

显示效果：

**加粗字体**

*斜体字体*

***加粗斜体***

~~删除线~~

## 六、列表

无序列表使用 `-` 或 `*`：

```markdown
- 列表项 1
- 列表项 2
	- 嵌套列表项
```

显示效果：

- 列表项 1
- 列表项 2
	- 嵌套列表项

有序列表使用数字加点：

1. 第一项
2. 第二项
3. 第三项

## 七、引用

使用 `>` 表示引用：

```markdown
> 这是一段引用内容
```

显示效果：

> 这是一段引用内容

## 八、分隔线

使用三个或以上的 `-` 或 `*`：

```markdown
---
```

显示效果：

---

## 九、图片

```markdown
![图片描述](figures/图片路径.png)
```

| `` `文字` `` | 行内代码 | `高亮` |
