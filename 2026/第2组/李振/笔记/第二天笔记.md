# RT‑Thread 线程学习笔记

## 一、线程基本概念

线程是 RT‑Thread 最小的调度单元。
一个进程里面可以包含多个线程，每个线程拥有独立的栈、上下文、优先级。
RT‑Thread 采用**抢占式优先级调度**。
高优先级线程一旦就绪，可以立刻抢占低优先级线程。

### 线程五大状态

2. **就绪态(RT_THREAD_READY)**
    线程已经具备运行条件，等待CPU调度。
3. **运行态(RT_THREAD_RUNNING)**
    当前正在占用CPU运行。单核同一时刻只能有一个线程处于运行态。
4. **阻塞态(挂起 RT_THREAD_SUSPEND)**
    线程主动放弃CPU，等待事件、延时、信号量、互斥锁。
5. **睡眠态 / 延时态**
    `rt_thread_mdelay()` 进入延时，时间到自动回到就绪态。
6. **关闭态(RT_THREAD_CLOSE)**
    线程已经结束，等待被系统回收资源。

> 状态流转简单总结：
> 就绪 →(调度)→运行 →(延时/等待资源)→阻塞；阻塞等待条件满足 →就绪。

## 二、线程重要参数

2. **线程优先级 priority**
    RT‑Thread 默认优先级范围：0 ~ 31
    **数字越小，优先级越高**。
3. **时间片 tick**
    相同优先级线程之间采用时间片轮转。时间片用完切换到同优先级下一个就绪线程。
4. **线程栈 stack**
    保存函数局部变量、寄存器上下文、中断现场。
    栈过小容易栈溢出、系统死机。

## 三、两种创建线程方式

### 方式1：动态创建 `rt_thread_create`

堆上分配线程控制块 + 线程栈

```
rt_thread_t tid;
tid = rt_thread_create("thread1",
                        thread_entry,
                        RT_NULL,
                        512,
                        10,
                        5);
if(tid != RT_NULL)
{
    rt_thread_startup(tid);
}
```

参数依次：线程名字、入口函数、入口参数、栈大小、优先级、时间片。

### 方式2：静态初始化 `rt_thread_init`

使用全局数组当做栈、全局`struct rt_thread`当做线程控制块，不使用堆内存。适合内存资源紧张、不允许动态内存的场景。

```
struct rt_thread tcb;
char thread_stack[512];

void thread_entry(void *param)
{
    
}

rt_thread_init(&tcb,
               "thread2",
               thread_entry,
               RT_NULL,
               thread_stack,
               sizeof(thread_stack),
               11,
               5);
rt_thread_startup(&tcb);
```

## 四、线程入口函数规范

线程函数是一个死循环或者执行完主动退出。

```
void thread_entry(void *param)
{
    while(1)
    {
        //业务代码
        rt_thread_mdelay(500);
    }
}
```

> 注意：线程里面必须要有**阻塞动作**（延时、等待信号量等），否则高优先级死循环线程会独占CPU，低优先级线程永远得不到运行。

## 五、常用线程API

```
//启动线程
rt_thread_startup(tid);

//线程延时，毫秒
rt_thread_mdelay(1000);

//让出CPU，主动释放一次时间片
rt_thread_yield();

//挂起指定线程
rt_thread_suspend(tid);

//恢复线程
rt_thread_resume(tid);

//获得当前正在运行线程
rt_thread_self();

//设置线程优先级
rt_thread_set_priority(tid,8);
```

## 六、线程删除

动态创建线程：

```
rt_thread_delete(tid);
```

静态线程：

```
rt_thread_detach(&tcb);
```

> 删除之后线程控制块、栈空间会被释放。线程函数不能直接return，如果需要结束线程调用`rt_thread_exit(RT_NULL);`

## 七、线程调度原理

2. 发生调度时机：

   - 线程调用延时、等待内核对象，主动放弃CPU
   - 高优先级线程就绪，抢占当前线程
   - 中断服务函数退出时触发调度
   - 同优先级线程时间片耗尽

3. 调度器会从**就绪列表**选出优先级最高的线程投入运行

## 八、多线程常见问题

2. **优先级反转**
   低优先级占用资源，高优先级等待，中间优先级任务抢占低优先级，导致高优先级迟迟不能运行。解决方案：互斥锁优先级继承。
3. **栈溢出**
   局部变量太大、递归太深，栈空间被破坏。现象：程序莫名hard‑fault。解决：调大栈空间。
4. **死锁**
   线程A持有锁1等待锁2；线程B持有锁2等待锁1。两个线程永久阻塞。
5. **多线程访问全局变量不加保护**
   产生数据竞争，数据错乱，需要信号量 / 互斥锁保护共享资源。

## 九、最小完整示例代码

```
#include <rtthread.h>

static void thread1_entry(void *param)
{
    while(1)
    {
        rt_kprintf("thread1 running\n");
        rt_thread_mdelay(1000);
    }
}

static void thread2_entry(void *param)
{
    while(1)
    {
        rt_kprintf("thread2 running\n");
        rt_thread_mdelay(1000);
    }
}

int thread_demo(void)
{
    rt_thread_t t1,t2;
    t1 = rt_thread_create("t1",thread1_entry,RT_NULL,512,10,5);
    if(t1) rt_thread_startup(t1);

    t2 = rt_thread_create("t2",thread2_entry,RT_NULL,512,11,5);
    if(t2) rt_thread_startup(t2);
    return RT_EOK;
}
MSH_CMD_EXPORT(thread_demo,thread demo);
```
