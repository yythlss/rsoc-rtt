

## 一、项目概述

**设计并实现一套纯软件虚拟字符设备驱动**。本设备无需依赖真实硬件外设，通过内存缓冲区模拟设备存储区域，完整实现设备初始化、打开、关闭、读取、写入、设备控制等标准驱动接口。

项目严格遵循 RT-Thread 驱动分层思想：**内核设备框架层、设备私有驱动层、用户应用层**三层解耦设计，完整展示 RT-Thread 设备模型的注册、管理与调用机制，适合理解嵌入式操作系统驱动开发模型。

### 2.1 设备整体架构

本虚拟设备采用经典三层架构：

2. **底层硬件模拟层**：使用内存缓冲区模拟设备存储，自定义设备状态统计结构体，记录设备打开次数、读写次数、控制次数与数据长度。
3. **驱动框架层**：适配 RT-Thread 标准 `rt_device` 驱动接口，实现 `init / open / close / read / write / control` 接口。
4. **应用测试层**：通过 FinSH 命令编写测试用例，完成设备全功能调用测试。

### 2.2 设备功能设计

虚拟设备具备以下功能：

- 设备初始化与资源清零
- 设备打开、关闭管理
- 支持任意偏移量的读写缓冲区
- 自动统计设备运行状态
- 自定义 IO 控制：设备缓存清零、设备状态读取

### 2.3 设备宏与命令设计

- 设备名称：`virt_dev`

- 设备缓冲区大小：256 字节

- 自定义控制命令：

  - 设备复位清零：`VIRT_DEV_CMD_RESET`
  - 获取设备状态统计：`VIRT_DEV_CMD_STATUS`

## 三、详细模块设计

### 3.1 设备私有数据模块

定义设备私有结构体，用于模拟硬件寄存器与设备状态：

- 设备打开标志位
- 设备统计信息：打开计数、读计数、写计数、控制计数、有效数据长度
- 设备数据缓存数组

所有驱动操作均基于该私有变量完成，实现驱动数据私有化。

### 3.2 标准驱动接口实现

#### 3.2.1 设备初始化 init

系统板级初始化时自动调用，清空设备缓存与统计数据，绑定设备私有数据到 `user_data`。

#### 3.2.2 设备打开 open

标记设备为打开状态，累加打开计数，返回设备就绪。

#### 3.2.3 设备关闭 close

清除设备打开标记，完成设备关闭资源回收。

#### 3.2.4 设备读 read

校验偏移与参数合法性，根据偏移量从设备缓存中拷贝数据到用户缓冲区，更新读计数。

#### 3.2.5 设备写 write

校验写入偏移与长度，将用户数据写入虚拟设备缓存，自动更新有效数据长度，更新写计数。

#### 3.2.6 设备控制 control

实现自定义设备命令：

- 复位命令：清空缓存、重置数据长度
- 状态获取命令：将设备统计信息导出给应用层

### 3.3 设备注册流程

2. 创建 RT-Thread 标准字符设备对象
3. 绑定所有驱动操作函数
4. 向内核注册设备名为 `virt_dev`
5. 系统启动自动完成设备初始化

### 3.4 应用测试模块

编写 FinSH 测试命令，自动完成：

- 查找虚拟设备
- 打开设备
- 写入测试字符串
- 读取并打印数据
- 获取并打印设备运行统计信息
- 复位清空设备
- 关闭设备
