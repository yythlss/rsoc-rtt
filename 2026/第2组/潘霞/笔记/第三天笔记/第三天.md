

# 一、线程间同步

**信号量**：互斥信号量/二值信号量（初始值为0不可获取；到达同步点释放信号量，值变为1，可获得）/计数信号量（被初始化为n，n为非负整数，n是共享资源的数量；信号量大于0时，可获得；信号量等于0，不可获得，挂起状态）

信号量控制块结构体

```c
struct rt_semaphore
{
   struct rt_ipc_object parent;  /* 继承自 ipc_object 类 */
   rt_uint16_t value;            /* 信号量的值 */
   rt_uint16_t max_value;        /* 信号量的最大值 */
   struct rt_spinlock spinlock;  /* 自旋锁 */
};
/* rt_sem_t 是指向 semaphore 结构体的指针类型 */
typedef struct rt_semaphore* rt_sem_t;
```

**创建信号量**

```c
 rt_sem_t rt_sem_create(const char *name,
                        rt_uint32_t value,
                        rt_uint8_t flag);
```

FIFO（先进先出）/PRIO（优先级等待）

**删除信号量**

```c
rt_err_t rt_sem_delete(rt_sem_t sem);
```

**初始化信号量**

```c
rt_err_t rt_sem_init(rt_sem_t       sem,
                    const char     *name,
                    rt_uint32_t    value,
                    rt_uint8_t     flag)
```

**脱离信号量**：让信号量对象从内核对象管理器中脱离，适用于静态初始化的信号量

```c
rt_err_t rt_sem_detach(rt_sem_t sem);
```

**获取信号量**：当信号量值大于零时，线程将获得信号量，并且相应的信号量值会减 1

```c
rt_err_t rt_sem_take (rt_sem_t sem, rt_int32_t timeout);
```

**无等待获取信号量**

```c
rt_err_t rt_sem_trytake(rt_sem_t sem);
```

**释放信号量**

```c
rt_err_t rt_sem_release(rt_sem_t sem);
```

**互斥量**

当线程持有它，互斥量处于闭锁状态，由这个线程获得它的所有权；当这个线程释放它时，将对互斥量进行开锁，失去它的所有权

当一个线程持有互斥量时，其他线程将不能对它进行开锁或持有它

**注：在获得互斥量后，请尽快释放互斥量，并且在持有互斥量的过程中，不得再行更改持有互斥量线程的优先级，否则可能人为引入无界优先级反转的问题。**

**互斥量控制块结构体**

```c
struct rt_mutex
{
    struct rt_ipc_object parent;        /* 继承自 ipc_object 类 */

    rt_uint8_t           ceiling_priority; /* 优先级天花板 */
    rt_uint8_t           priority;         /* 等待线程中的最高优先级 */
    rt_uint8_t           hold;             /* 持有线程的持有次数 */
    rt_uint8_t           reserved;         /* 保留字段 */

    struct rt_thread    *owner;            /* 当前拥有互斥量的线程 */
    rt_list_t            taken_list;       /* 线程持有的对象链表 */
    struct rt_spinlock   spinlock;         /* 自旋锁 */
};
/* rt_mutex_t 为指向互斥量结构体的指针类型  */
typedef struct rt_mutex* rt_mutex_t;
```

**创建互斥量**

```c
rt_mutex_t rt_mutex_create (const char* name, rt_uint8_t flag);
```

**删除互斥量**

```c
rt_err_t rt_mutex_delete (rt_mutex_t mutex);
```

 **初始化互斥量**

```c
rt_err_t rt_mutex_init (rt_mutex_t mutex, const char* name, rt_uint8_t flag);
```

**脱离互斥量**

```c
rt_err_t rt_mutex_detach (rt_mutex_t mutex);
```

**获取互斥量**

```c
rt_err_t rt_mutex_take (rt_mutex_t mutex, rt_int32_t timeout);
```

**无等待获取互斥量**

```c
rt_err_t rt_mutex_trytake(rt_mutex_t mutex);
```

**释放互斥量**

```c
rt_err_t rt_mutex_release(rt_mutex_t mutex);
```



**互斥量和信号量不同的是：拥有互斥量的线程拥有互斥量的所有权，互斥量支持递归访问且能防止线程优先级翻转；并且互斥量只能由持有线程释放，而信号量则可以由任何线程释放。**



**事件集**

可以实现一对多、多对多的同步

这种多个事件的集合可以用一个 32 位无符号整型变量来表示，变量的每一位代表一个事件，线程通过 “逻辑与” 或“逻辑或”将一个或多个事件关联起来，形成事件组合。

每一个线程可拥有32个事件标志，事件仅用于同步，不提供数据传输功能

**事件集控制块结构体**

```c
struct rt_event
{
    struct rt_ipc_object parent;    /* 继承自 ipc_object 类 */

    /* 事件集合，每一 bit 表示 1 个事件，bit 位的值可以标记某事件是否发生 */
    rt_uint32_t set;
    struct rt_spinlock spinlock;
};
/* rt_event_t 是指向事件结构体的指针类型  */
typedef struct rt_event* rt_event_t;
```

**创建事件集**

```c
rt_event_t rt_event_create(const char* name, rt_uint8_t flag);
```

**删除事件集**

```c
rt_err_t rt_event_delete(rt_event_t event);
```

**初始化事件集**

```c
rt_err_t rt_event_init(rt_event_t event, const char* name, rt_uint8_t flag);
```

**脱离事件集**

```c
rt_err_t rt_event_detach(rt_event_t event);
```

**发送事件**

```c
rt_err_t rt_event_send(rt_event_t event, rt_uint32_t set);
```

**接收事件**

```c
rt_err_t rt_event_recv(rt_event_t event,
                           rt_uint32_t set,
                           rt_uint8_t opt,
                           rt_int32_t timeout,
                           rt_uint32_t* recved);
```



# 二、线程间通信

**邮箱**

开销低、效率高

**邮箱控制块结构体**

```c
struct rt_mailbox
{
    struct rt_ipc_object parent;

    rt_uint32_t* msg_pool;                /* 邮箱缓冲区的开始地址 */
    rt_uint16_t size;                     /* 邮箱缓冲区的大小     */

    rt_uint16_t entry;                    /* 邮箱中邮件的数目     */
    rt_uint16_t in_offset, out_offset;    /* 邮箱缓冲的进出指针   */
    rt_list_t suspend_sender_thread;      /* 发送线程的挂起等待队列 */
    struct rt_spinlock spinlock;          /* 自旋锁 */
};
typedef struct rt_mailbox* rt_mailbox_t;
```



**动态创建邮箱**

```c
rt_mailbox_t rt_mb_create (const char* name, rt_size_t size, rt_uint8_t flag);
```

**删除邮箱**

```c
rt_err_t rt_mb_delete (rt_mailbox_t mb);
```

**初始化邮箱**

```c
  rt_err_t rt_mb_init(rt_mailbox_t mb,
                    const char* name,
                    void* msgpool,
                    rt_size_t size,
                    rt_uint8_t flag)
```

**脱离邮箱**

```c
rt_err_t rt_mb_detach(rt_mailbox_t mb);
```

**发送邮件**：线程或者中断服务程序可以通过邮箱给其他线程发送邮件

```c
rt_err_t rt_mb_send (rt_mailbox_t mb, rt_ubase_t value);
```

**等待方式发送邮件**：用户向指定邮箱发送邮件

```c
rt_err_t rt_mb_send_wait (rt_mailbox_t mb,
                      rt_ubase_t  value,
                      rt_int32_t  timeout);
```

**发送紧急邮件**

```c
rt_err_t rt_mb_urgent (rt_mailbox_t mb, rt_ubase_t value);
```

**接收邮件**

```c
rt_err_t rt_mb_recv (rt_mailbox_t mb, rt_ubase_t *value, rt_int32_t timeout);
```



**消息队列**

线程间的消息交换、使用串口接收**不定长数据**

**消息队列控制块结构体**

```c
struct rt_messagequeue
{
    struct rt_ipc_object parent;

    void* msg_pool;                     /* 指向存放消息的缓冲区的指针 */

    rt_uint16_t msg_size;               /* 每个消息的长度 */
    rt_uint16_t max_msgs;               /* 最大能够容纳的消息数 */

    rt_uint16_t entry;                  /* 队列中已有的消息数 */

    void* msg_queue_head;               /* 消息链表头 */
    void* msg_queue_tail;               /* 消息链表尾 */
    void* msg_queue_free;               /* 空闲消息链表 */

    rt_list_t suspend_sender_thread;    /* 发送线程的挂起等待队列 */
    struct rt_spinlock spinlock;        /* 自旋锁 */
};
typedef struct rt_messagequeue* rt_mq_t;
```

**创建消息队列**

```c
rt_mq_t rt_mq_create(const char* name, rt_size_t msg_size,
            rt_size_t max_msgs, rt_uint8_t flag);
```

**删除消息队列**

```c
rt_err_t rt_mq_delete(rt_mq_t mq);
```

**初始化消息队列**

```c
rt_err_t rt_mq_init(rt_mq_t mq, const char* name,
                        void *msgpool, rt_size_t msg_size,
                        rt_size_t pool_size, rt_uint8_t flag);
```

**脱离消息队列**

```c
rt_err_t rt_mq_detach(rt_mq_t mq);
```

**发送消息**

```c
rt_err_t rt_mq_send (rt_mq_t mq, const void *buffer, rt_size_t size);
```

**等待方式发送消息**

```c
rt_err_t rt_mq_send_wait(rt_mq_t     mq,
                         const void *buffer,
                         rt_size_t   size,
                         rt_int32_t  timeout);
```

**发送紧急消息**

```c
rt_err_t rt_mq_urgent(rt_mq_t mq, const void *buffer, rt_size_t size);
```

**接收消息**

```c
rt_ssize_t rt_mq_recv(rt_mq_t    mq,
                    void      *buffer,
                    rt_size_t  size,
                    rt_int32_t timeout);
```
