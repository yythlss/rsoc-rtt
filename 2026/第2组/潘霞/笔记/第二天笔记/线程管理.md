# 一、嵌入式实时操作系统

裸机模式缺陷：并发性、实时性、可维护性、可重用性

### 任务的实体：线程（“分而治之”）

### RTOS精髓：多任务系统（并不是真正的同时进行多个任务，只是每个任务之间的间隔时间很短，在看起来就是多个任务同时进行）

![启动流程](D:\TYPORA\figures\rtt_startup.png)

board函数：初始化串口

main（）函数优先级为10（timer可设置为4），idle函数的优先级最低（31）

### 线程控制块（管理线程的顺序）

线程：线程控制块+入口函数

结构体继承自基类：rt_object

## 线程属性

线程栈：线程具有独立的栈空间

线程状态：初始状态、就绪状态、运行状态、挂起状态、关闭状态

从运行到挂起：delay延时，信号量、互斥量的获取；

从挂起到运行的回复：信号量的释放；

创建线程可以动态创建rt_thread_create()，也可以静态创建rt_thread_init()

优先级：最大支持256个线程优先级（0-255），数值越小优先级越高，最低优先级默认分配给空闲线程使用（idle）

时间片：优先级相同时，时间片起作用（仅对优先级相同的就绪态起作用）

入口函数：void(*entry)(void * parameter)

空闲线程（idle）：优先级最低，线程状态永远为就绪态。通常是一个死循环，永远不能被挂起。主要用于：资源回收，提供钩子函数（钩入功耗管理、看门狗喂狗等工作）

# 二、SCons构建系统

SCons是RT-Thread常见的构建工具，主要用于管理工程编译过程，基于Python脚本描述工程结构，能够自动完成源文件扫描、编译、链接和工程生成

### 1.SCons的作用

1.1管理工程源文件

1.2配置编译器和链接器

1.3设置头文件路径

1.4设置宏定义和编译选项

1.5执行增量编译

1.6生成目标文件和工程文件

### 2.常见文件

RT-Thread工程中常见的构建文件包括：SConstruct、SConscript、rtconfig.py、Kconfig

### 3.构建流程

读取SConstruct->解析各目录下的SConscript->收集源文件和依赖关系->调用编译器->调用链接器->生成ELF/HEX/BIN文件

### 4.常见命令

```
scons #编译工程
```

```
scons -j4 #使用4个并行任务编译
```

```
scons --target=mdk5  #生成Keil MDK5工程
```
