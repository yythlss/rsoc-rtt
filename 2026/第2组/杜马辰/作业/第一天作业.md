## 7. 编写 Hello World 程序

进入示例工程：

```bash
source /Users/gatesbil/Documents/Project/stm32/rtthread-mac-env.sh
spark_project 01_kernel
```

应用程序入口文件：

```text
applications/main.c
```

示例代码：

```c
#include <rtthread.h>

#define DBG_TAG "main"
#define DBG_LVL DBG_LOG

#include <rtdbg.h>

int main(void)
{
    int count = 1;

    rt_kprintf("hello RSOC2026!\n");

    while (count++)
    {
        LOG_D("Hello RT-Thread!");
        rt_thread_mdelay(1000);
    }

    return RT_EOK;
}
```

代码含义：

```text
rt_kprintf：通过 RT-Thread 控制台输出字符串
LOG_D：输出 Debug 级别日志
rt_thread_mdelay：让当前线程延时，单位为毫秒
```

## 9. 检查开发板和下载固件

连接开发板 USB 数据线并给开发板上电：

```bash
st-info --probe
```

使用 OpenOCD 下载 ELF 文件：

```bash
openocd \
  -f interface/stlink.cfg \
  -f target/stm32f4x.cfg \
  -c "program rt-thread.elf verify reset exit"
```

命令含义：

```text
-f interface/stlink.cfg：使用 ST-Link 下载器配置
-f target/stm32f4x.cfg：使用 STM32F4 芯片配置
program：烧录固件
verify：烧录后校验
reset：复位目标芯片
exit：完成后退出 OpenOCD
```
