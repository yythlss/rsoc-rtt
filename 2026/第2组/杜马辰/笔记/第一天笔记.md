## 5. 创建 macOS 环境脚本

```text

```

脚本内容：

```bash
#!/usr/bin/env bash

RTT_LOCAL_ROOT="/Users/gatesbil/Documents/Project/stm32"
export RTT_LOCAL_ROOT
export SPARK_SDK_ROOT="$RTT_LOCAL_ROOT/sdk-bsp-stm32f407-spark"
export RTT_CC="gcc"
export RTT_EXEC_PATH="/opt/homebrew/bin"
export PATH="$RTT_LOCAL_ROOT/.venv/bin:/opt/homebrew/bin:$PATH"

spark_project() {
    if [ "$#" -ne 1 ]; then
        echo "usage: spark_project <project-directory>" >&2
        return 2
    fi

    cd "$SPARK_SDK_ROOT/projects/$1"
}

echo "RT-Thread environment loaded"
echo "SPARK_SDK_ROOT=$SPARK_SDK_ROOT"
echo "RTT_EXEC_PATH=$RTT_EXEC_PATH"
```

## 8. 处理 CubeMX 的 `crdb_full.zip` 报错

错误信息：

```text
Error downloading the following files:
crdb_full.zip
Problem during download
```

含义：

```text
CubeMX 在线刷新 MCU/开发板数据库失败
```

不是以下问题：

```text
不是 STM32F407 不支持
不是 Spark-1 BSP 选错
不是 STM32F4 软件包选错
```

检查 CubeMX 版本：

```text
Help → About
```

升级 CubeMX：

```text
Help → Check for Updates
```

如果在线升级失败，手动下载 macOS Arm64 版本并安装。

临时关闭启动自动刷新：

```text
Help → Connection and Updates
→ No Auto-Refresh at Application start
```

Spark-1 LED 引脚：

```c
#define PIN_LED_B GET_PIN(F, 11)
#define PIN_LED_R GET_PIN(F, 12)
```

红色 LED 闪烁代码：

```c
#include <rtthread.h>
#include <rtdevice.h>
#include <board.h>

#define PIN_LED_R GET_PIN(F, 12)

int main(void)
{
    rt_pin_mode(PIN_LED_R, PIN_MODE_OUTPUT);

    while (1)
    {
        rt_pin_write(PIN_LED_R, PIN_LOW);
        rt_thread_mdelay(500);
        rt_pin_write(PIN_LED_R, PIN_HIGH);
        rt_thread_mdelay(500);
    }
}
```

## 11. CubeMX 生成文件的处理

RT-Thread 工程中不要直接加入 CubeMX 普通工程的全部文件。

需要避免重复的文件和函数：

```text
main.c
stm32f4xx_it.c
SysTick_Handler
```

原因：

```text
RT-Thread BSP 已经负责系统入口、启动流程和 SysTick
CubeMX 主要用于生成时钟、GPIO、外设和 HAL MSP 配置
applications/main.c 用于编写 RT-Thread 应用
```

修改 `.ioc` 后，检查生成的文件是否被当前工程的 `SConscript` 加入，避免出现重复定义。

## 15. 直接编译主线 BSP 时的文件关系

主线 BSP 地址：

```text
https://github.com/RT-Thread/rt-thread/tree/master/bsp/stm32/stm32f407-rt-spark
```

不能只保留目标 BSP 目录，至少需要保留：

```text
rt-thread/
├── src/
├── include/
├── components/
├── tools/
├── packages/
└── bsp/stm32/stm32f407-rt-spark/
```

`bsp` 下其他开发板目录不是目标 BSP 的直接编译依赖，可以不使用；但 RT-Thread 根目录的内核和构建工具不能删除。

主线 BSP 构建脚本检查的依赖目录：

```text
packages/CMSIS-Core-latest/
packages/stm32f4_cmsis_driver-latest/
packages/stm32f4_hal_driver-latest/
```

RT-Thread Env 中更新依赖：

```bash
pkgs --update
```

进入主线 BSP：

```bash
cd rt-thread/bsp/stm32/stm32f407-rt-spark
```

编译：

```bash
scons -j4
```

macOS 下如果没有 `pkgs` 命令，使用已经整理好 `libraries` 的官方 SDK。
