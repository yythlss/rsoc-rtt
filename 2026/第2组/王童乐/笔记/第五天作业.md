# 【RSOC26】RT-Thread 夏令营第五天作业学习笔记

## 一、作业目标

本次作业把 RT-Thread 软件包、网络通信和文件系统串成一个完整应用：使用 AHT10 采集温湿度，每 2 秒通过 MQTT 上传到 EMQX；同时将同一份数据追加写入 Flash 文件系统的 `Data.txt`；订阅云端控制主题，收到 `LED_TOGGLE` 后翻转板载 LED；并复习 DFS 挂载流程和常用 Shell 命令。

## 二、AHT10 温湿度采集

在 `menuconfig` 中启用 AHT10 软件包、Sensor 框架和对应 I2C 总线。程序调用 `aht10_init` 获取设备句柄，再调用 `aht10_read_temperature`、`aht10_read_humidity` 读取数据。采集线程每 2 秒执行一次，并通过 MSH 命令导出，方便串口调试。

默认 libc 可能不支持浮点格式化，因此需要启用 `rt_vsnprintf_full`，否则温湿度值打印可能不完整或显示异常。AHT10 的 I2C 总线名、设备地址需要按实际开发板原理图填写。

## 三、MQTT/EMQX 上报

启用 `cJSON` 和 `cai_mqtt` 软件包，配置 EMQX 地址、端口 `1883`、客户端 ID、用户名密码和发布/订阅主题。每次采样发布一条 JSON 消息，示例：

```json
{"temp":25.31,"humi":48.62,"count":1}
```

其中 `count` 从上电开始计数，每次采样加一。使用 MQTT.fx 订阅设备发布主题，检查消息是否每 2 秒到达且计数连续。

## 四、DFS 文件系统与 Flash

### 4.1 启动和挂载流程

1. 在 `menuconfig` 中依次启用 DFS、elm 文件系统、SFUD 和 Flash 自动挂载。
2. 通过分区表把 W25Q64 划分为固件区、下载区和文件系统区。
3. 初始化 SPI 总线、SFUD Flash 驱动和分区设备。
4. DFS 注册块设备并执行挂载，将文件系统挂载到 `/font`。
5. 应用线程通过 POSIX 接口访问 `/font/Data.txt`。

SFUD 屏蔽了不同 SPI Flash 芯片的底层差异，应用只需要使用统一的块设备接口。WiFi 和 Flash 共用 SPI 时，应在初始化阶段上拉 RW007 片选，避免未选中设备占用总线。

### 4.2 Data.txt 写入格式

每次采样同时追加一行文本，格式如下：

```text
Temp：25.31 ; Humi：48.62 ; Count：1
Temp：25.42 ; Humi：48.57 ; Count：2
Temp：25.38 ; Humi：48.60 ; Count：3
```

示例 POSIX 写入流程：打开 `/font/Data.txt`（追加模式），格式化一行温湿度和计数，调用 `write` 写入，最后 `close`。写入失败时记录错误并保留 MQTT 上报线程运行，避免单个存储故障阻塞网络任务。

## 五、Shell 命令复习

```text
help                    # 查看可用命令
wifi scan               # 扫描 WiFi
wifi connect <ssid> <password>
ping <server>           # 验证网络
df                      # 查看文件系统空间
ls /                    # 查看根目录挂载点
ls /font                # 查看文件系统目录
cat /font/Data.txt      # 查看采样记录
mount font /font        # 自动挂载失败时手动挂载
umount /font            # 卸载文件系统
```

验证重点是：`ls /font` 能看到目录，`cat /font/Data.txt` 能看到持续追加的记录，重启后文件内容仍然存在。

## 六、云端控制 LED 翻转

设备订阅控制主题，例如 `rsoc26/board/cmd`。收到消息 `LED_TOGGLE` 后读取当前 LED 电平并写入相反电平，实现一次翻转；未知消息只记录日志，不改变 LED 状态。使用 MQTT.fx 发布 `LED_TOGGLE`，结合板载 LED 和串口输出验证控制结果。

## 七、其他软件包学习

- `cJSON`：将采样结构转换为 MQTT JSON 消息。
- `cai_mqtt`：提供 MQTT 连接、订阅和发布能力。
- `rt_vsnprintf_full`：补充浮点格式化支持。
- `SFUD`：提供统一的 SPI Flash 读写和擦除接口。
- `AHT10`、`Sensor`：完成传感器设备注册和数据读取。

软件包使能后要同时检查 Kconfig 依赖。AHT10 依赖 Sensor 框架，DFS 文件访问依赖文件系统、块设备和 Flash 分区配置，依赖项缺失会导致编译或挂载失败。
