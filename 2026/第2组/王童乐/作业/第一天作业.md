# 第一天作业

## 学习总结

今天是 RT-Thread 夏令营 Day1，我主要学习了嵌入式系统的启动流程、裸机和 RTOS 的区别，以及 RT-Thread 的源码入口思路。

上午我重点理解了：
- 裸机程序的启动入口
- 不同工具链下入口函数的差异
- 从汇编入口到 C 语言入口的完整流程

下午我重点理解了：
- ARM F407 平台上的启动链路
- `reset_handler` 到 `main` 的执行过程
- `INIT_APP_EXPORT` 这类初始化宏的作用
- `SysTick`、外设初始化和调度器启动的关系

我现在的理解是：RT-Thread 不是简单把 `main()` 当普通函数执行，而是把它放进线程体系里。也就是说，系统真正开始并发调度后，程序才进入 RTOS 的运行方式。

## 我的学习体会

刚开始听这部分内容时，我会觉得启动流程很零散，很多名词也比较陌生。但是老师把流程按“上电 -> 初始化 -> 入口 -> 调度器 -> 线程”这样串起来以后，我就能慢慢把它们连成一条线了。

对我来说，最有帮助的一点是：不要只背结论，要去看源码里每一步是怎么接上的。这样理解会更稳，也更容易记住。
