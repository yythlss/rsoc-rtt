## 下午学习任务：Git工具的运用

**环节1：环境准备**

-   **本地软件安装** 原生 Git 工具+图形化Git工具 TortoiseGit 
-   **远端仓库创建** 注册 Gitee 账号并新建远程仓库（右上角加号 → 新建仓库 → 填名称 → 创建）

**环节2：身份与密钥配置**

-   **配置全局用户名** `git config --global user.name "xxx"`
-   **配置全局邮箱** `git config --global user.email "xxx"`
-   **生成 SSH 密钥** `ssh-keygen`（一路回车三次）
-   **查看公钥内容** `cat ~/.ssh/id_rsa.pub`
-   **验证密钥连通** `ssh -T git@gitee.com`（输入 yes）

**环节3：仓库初始化与基础提交**

-   **初始化本地仓库** `git init`
-   **查看当前状态** `git status`
-   **拉取远端最新** `git pull origin master`
-   **添加文件到暂存区** `git add README.md`（或 `git add .`）
-   **提交到本地版本库** `git commit -m "初次提交"`
-   **推送到远端分支** `git push origin master`

**环节4：分支管理与 PR 协作**

-   **基于当前分支切新分支** `git checkout -b test`
-   **切换已有分支** `git switch master`
-   **查看远端地址** `git remote -v`
-   **修改远端地址** `git remote set-url origin <ssh_url>`
-   **Fork 上游仓库**
-   **网页端发起 PR**
-   **代码评审与合并**

**环节5：日常迭代同步**

-   **切回主干** `git switch master`
-   **拉取主干最新** `git pull`
-   **开新分支** `git checkout -b day2`
-   **全量暂存** `git add .`
-   **提交日志** `git commit -m "second commit"`
-   **推新分支并发 PR** `git push origin day2`
