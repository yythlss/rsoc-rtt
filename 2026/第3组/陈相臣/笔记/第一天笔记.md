# 第一天笔记 - RT-Thread 与 Git

## 一、夏令营安排

- 第一周为学习周，上午 9:00-12:00 授课，下午 14:00 后实操与完成作业。
- 第二周为项目周，学员分组完成项目任务。

## 二、RT-Thread 生态与开发环境

### 1. 环境配置

1. 安装 RT-Thread Studio。
2. 通过 SDK Manager 下载 RT-Thread 4.0.3 源码和 STM32F4 芯片支持包。
3. 在设备管理器中确认 ST-Link 驱动正常识别。

### 2. 工程创建与调试

1. 基于 STM32F407 创建工程，选择 Nano 或标准版内核，串口波特率设为 115200。
2. 编译生成 `.elf` 和 `.bin` 文件。
3. 使用 ST-Link 下载到开发板，通过终端查看启动日志。
4. 使用断点调试验证程序运行情况。

## 四、Git 基础操作与 PR 流程

### 1. 常用命令

```bash
git init                    # 初始化本地仓库
git clone <仓库地址>          # 克隆远程仓库
git pull origin master      # 拉取远程 master 分支
git add <文件/路径>          # 添加到暂存区
git commit -m "说明"        # 提交到本地仓库
git push origin master      # 推送到远程仓库
git remote -v               # 查看远程仓库地址
git remote set-url origin <地址> # 修改远程仓库地址
git checkout -b <分支名>     # 创建并切换分支
git switch <分支名>          # 切换分支
git fetch origin master      # 同步远程分支，不自动合并
```

### 2. Fork 与 PR 流程

```text
Fork 上游仓库 -> 克隆个人仓库 -> 创建功能分支 -> 开发 -> push -> 创建 PR -> 审核合并
```

- 开发在独立功能分支进行，例如 `day1`、`day2`，不要直接修改 `master`。
- 使用 `git remote add upstream <上游地址>` 关联上游，通过 `git fetch upstream` 或 `git pull` 同步最新代码。
- 生成 SSH 密钥并添加公钥到 Git 平台，用于免密认证。
