# 第一天笔记 - Git 基本命令

## 一、Git 简介

Git 是一个分布式版本控制系统，用于跟踪文件的变更，便于多人协作开发。

## 二、初始配置

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

## 三、基本命令

### 1. 创建仓库

```bash
git init                    # 在当前目录初始化一个 Git 仓库
git clone <仓库地址>         # 克隆远程仓库到本地
```

### 2. 查看状态

```bash
git status                  # 查看工作区和暂存区的状态
git log                     # 查看提交历史
git log --oneline           # 简洁版提交历史
```

### 3. 添加与提交

```bash
git add <文件名>            # 将指定文件添加到暂存区
git add .                   # 将所有修改添加到暂存区
git commit -m "提交说明"     # 将暂存区的内容提交到本地仓库
```

### 4. 远程操作

```bash
git remote add origin <地址>  # 关联远程仓库
git push origin <分支名>      # 推送到远程仓库
git pull origin <分支名>      # 拉取远程仓库并合并
git fetch                     # 拉取远程仓库（不自动合并）
```

### 5. 分支操作

```bash
git branch                   # 查看本地分支
git branch <分支名>          # 创建新分支
git checkout <分支名>        # 切换分支
git checkout -b <分支名>     # 创建并切换到新分支
git merge <分支名>           # 将指定分支合并到当前分支
git branch -d <分支名>       # 删除分支
```

### 6. 撤销与回退

```bash
git checkout -- <文件名>     # 撤销工作区的修改
git reset HEAD <文件名>      # 撤销暂存区的修改（放回工作区）
git reset --hard <commit_id> # 回退到指定提交版本
```

### 7. 其他常用命令

```bash
git diff                     # 查看工作区与暂存区的差异
git stash                    # 暂存当前修改
git stash pop                # 恢复暂存的修改
```

## 四、工作流程总结

```
工作区 --git add--> 暂存区 --git commit--> 本地仓库 --git push--> 远程仓库
```

1. 在工作区修改文件
2. `git add` 将修改放入暂存区
3. `git commit` 将暂存区提交到本地仓库
4. `git push` 将本地仓库推送到远程仓库
