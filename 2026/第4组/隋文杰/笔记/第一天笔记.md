## 3.git命令



```git
git init //初始化本地仓库
git clone xxx/xx.git //克隆你需要的仓库
git checkout -b day1     //创建并切换到新分支
//添加你的文件后
git add . //将所有修改添加到暂存区
git commit -m "提交说明"  //# 将暂存区的内容提交到本地仓库
git push -u origin day1 //新分支push

然后去网页上提交PR即可
```
