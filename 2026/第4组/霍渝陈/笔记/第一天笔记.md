# 二.Git的使用

## 基础命令

|     命令      |           功效           |
| :-----------: | :----------------------: |
|   git init    |      初始化当前目录      |
|   git add .   |     添加文件到暂存区     |
|  git commit   | 将暂存区内容添加到仓库中 |
| git checkout  |         切换分支         |
|  git remote   |       远程仓库操作       |
| git pull/push |   下载/上传代码并合并    |
|               |                          |

## 提交pr流程

​	1.在自己的仓库添加一个fork

​	2.`git clone` 将原代码拷到电脑上

​	3.对代码进行修改

​	4.`git checkout -b <你的分支名> `创建分支

​	5.`git add .` `git commit -m <描述>`,将文件添加到仓库中

​	6.`git push`上传代码并合并

​	7.去Gitee Pull Requests
